# YouTube Video Analyzer

An AI-powered YouTube Video Analyzer built using Python, Streamlit, Agno, and Groq.

This application allows users to enter a YouTube video URL and generate an AI-based summary of the video. It extracts the main topics, important points, and key takeaways in simple and understandable language.

## Features

- Analyze YouTube videos using an AI agent
- Generate clear and concise video summaries
- Extract important topics and key takeaways
- Simple and interactive Streamlit interface
- Powered by Groq's fast language models
- Built using the Agno agent framework

## Technologies Used

- Python
- Streamlit
- Agno
- Groq
- YouTube Tools
- python-dotenv
